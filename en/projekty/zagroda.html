Origin

A project born from a parent's need

Zagroda was born from a very personal need. As a parent I was looking for a way to motivate my child to learn — not through pressure, but through play. Maths doesn't have to be a nightmare. Spelling doesn't have to feel like a punishment. They can be enjoyable — if you package them right.

Available platforms were either too expensive, didn't connect with children, or lacked the element that was key for me: real rewards that a child can actually "spend". I decided to build it myself.

Zagroda combines education with economics — children earn stars for completing tasks and exchange them for pocket money set by the parent. Learning gains real value and purpose.

How it works

The platform runs in the browser — no installation, on any computer, tablet or phone. Three user roles define how the system is used:

👧
Child

Completes tasks, earns stars, tracks progress and reward balance.

👨‍👩‍👧
Parent

Sets the star-to-money rate, approves pocket money payouts, monitors progress. PIN access.

👨‍🏫
Teacher

Manages tasks, dictations, difficulty levels and exercise sets.

Modules and features

  • Maths — tasks adapted to the child's grade level. Four operations, fractions, word problems. The system generates tasks at the appropriate difficulty.
  • Spelling — Polish spelling exercises. Fill in the blanks, choose the correct form, work with vocabulary lists.
  • Custom dictation module — a parent or teacher inputs text, the child types it out. The system checks and scores. Works with actual school material.
  • Star system — every correctly completed task earns stars. The reward scale depends on difficulty.
  • Pocket money — the parent sets how much money one star is worth. The child sees their "balance" and knows when they can ask for a payout.
  • PIN-based parental access — secure access to the parent panel without a full login — just a PIN.
  • Progress history — the child and parent can see a history of completed tasks, stars earned and progress over time.

Project potential

Zagroda is a project I actively develop and improve. Testing with real users — children and parents — lets me iterate quickly toward genuine needs.

I see enormous potential in this platform — particularly given the growing edtech market and demand for tools that combine learning with motivation. The economics element — stars exchangeable for pocket money — is an innovation no competing platform in Poland currently offers.

The project also demonstrates that it's possible to build a complete, multi-role web platform with a database and permission system fully serverless — at near-zero hosting cost. Cloudflare Workers and D1 SQLite do the heavy lifting.
